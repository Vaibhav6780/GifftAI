# GIFFT AI — PREMIUM SOFTWARE COMPANY WEBSITE

You are a **world-class product designer, creative director, UX engineer, and senior frontend engineer**.

Your task is to design and build a **beautiful, premium, highly polished website for GIFFT AI (gifftai.com)**.

This is not a generic corporate website.

It should feel like a company that builds **serious, sophisticated software products**.

Think of the quality bar as a combination of:

* premium technology company
* high-end product studio
* modern AI company
* elite software engineering firm
* exceptional SaaS design

The website should immediately communicate:

> **GIFFT AI builds software that businesses actually run on.**

The design must be **original, memorable, elegant and technically impressive**.

Do not make it look like a template.

---

# FIRST: RESEARCH & THINK

Before implementing anything, study the design language of excellent modern software/product companies and agencies.

Look at how the best companies handle:

* typography
* whitespace
* navigation
* portfolio presentation
* case studies
* interaction design
* visual storytelling
* dark/light themes
* micro-interactions
* CTAs
* responsive layouts

Take inspiration from the **quality and principles**, but do NOT copy another company's website.

GIFFT AI needs its own visual identity.

Think:

**"If this website appeared on Awwwards, it should feel worthy of being there."**

But do not sacrifice usability for visual effects.

# LIGHT + DARK MODE

This is extremely important.

Build **two genuinely beautiful themes**.

Do NOT create a dark website and simply invert its colors for light mode.

Both themes need their own carefully considered visual hierarchy.

## DARK MODE

Direction:

* deep charcoal / near-black
* slightly lighter surfaces
* warm white typography
* muted gray secondary text
* subtle borders
* very restrained GIFFT accent
* subtle atmospheric gradients

The dark mode should feel:

**technical + premium + cinematic**

## LIGHT MODE

Direction:

* sophisticated off-white background
* clean white surfaces
* dark charcoal typography
* muted gray secondary text
* subtle borders
* restrained accent color

The light mode should feel:

**editorial + premium + architectural**

Both should look like the primary design.

Add a beautiful theme switcher in the navbar.

Persist the selected theme.

Respect system preference on first visit.

Theme switching should be smooth.

3. **Make it feel original.**
4. **Make the portfolio the hero of the company.**
5. **Make the software itself the visual identity.**
6. **Use whitespace confidently.**
7. **Use typography as a design element.**
8. **Do not fill empty space just because it is empty.**
9. **Do not use generic SaaS layouts everywhere.**
10. **Do not overuse rounded cards.**
11. **Do not overuse gradients.**
12. **Do not use stock photos.**
13. **Do not fabricate company information.**
14. **Light mode must be as beautiful as dark mode.**
15. **Dark mode must be as beautiful as light mode.**
16. **Every section should feel intentionally art-directed.**
17. **Every animation should have a purpose.**
18. **The website must be fast despite looking sophisticated.**
19. **Mobile must receive the same design attention as desktop.**
